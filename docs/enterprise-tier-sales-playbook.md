## 1. 一句話定位

> **企業版是「不設額度上限、由業務議價、以合約計費」的 OnBrand。**
> 自助方案（基礎版／專業版）賣的是「一個品牌的內容產能」；企業版賣的是「整個組織的品牌一致性基礎建設」——無限品牌、無限席次、共用點數池、白牌，以及專人導入。

對外講法（可直接使用）：

> OnBrand 把品牌定位寫進 Brand Brain，再由多個 AI Agent 依通路規格產出、審核並排程發布內容。企業版把這套流程開放給整個組織：不限品牌數、不限使用席次、集團共用一個點數池並可逐人設定用量上限，加上白牌與專人導入。

## 3. 企業版實際包含什麼

### ✅ 已在程式碼中實作（可以寫進提案）

| 能力 | 實際行為 |
| --- | --- |
| 無限品牌 | 品牌建立不受數量限制（`brandRouter.ts` 的 quota 檢查對 `brands: -1` 直接放行）。 |
| 無限席次 | `team_members: -1`。 |
| 無限點數 | `pointsPerCycle: -1`；點數引擎偵測到即補到 9,999,999 點（`pointsService.refillIfDue`）。使用者端不會看到任何點數牆。 |
| 免除每日成本上限 | 試用帳號每日 LLM 成本上限 US$5、付費 US$50；**企業版在 `preflightCostCheck` 第一行直接放行**，沒有每日上限。 |
| 無限發布 | `fb_publish: -1`；影片 `video_gen: -1`（其餘方案為 0，影片目前下架）。 |
| 多客戶／子品牌共用 | `multi_client: true`。 |
| 白牌 | 可改 workspace 的 `whiteLabelName` / `whiteLabelLogo`；後端只放行 `drop_agency` 與 `enterprise`（`tenantRouter.update`）。 |
| 企業共用點數池 | `enterprise_credits_pool` / `enterprise_members` / `enterprise_credits_allocation` / `enterprise_credits_tx` 四張表已上線。扣點順序為：**企業池 →個人方案額度 → 加購點數**，並支援**每位成員的每月用量上限**（`memberMonthlyLimit`），每一筆扣點都進流水帳。 |
| 登入稽核軌跡 | `login_audit_log`（對應 ISO 27001 A.12.4）記錄登入事件、IP、User-Agent。 |
| 個資請求 | 帳號資料匯出 JSON 與帳號軟刪除（30 天後硬刪）已實作（`billingRouter`，PDPA 準備）。 |
| B2B 電子發票 | 發票資料在帳戶頁可查。 |

### ⚠️ 已實作但目前「只能由 Ops 操作」（可以承諾，但要講清楚交付方式）

- **企業點數池沒有自助管理介面**：加值、設定每人上限、邀請成員目前只有資料表與扣點邏輯，沒有前台 UI。要當成**由我方 Ops 代管的服務**來賣，不要展示成客戶自助後台。
- **企業版方案開通沒有安全的一鍵流程**：`admin-grant-plan.yml`（一般開通工具）**刻意排除 enterprise**，因為企業版會跳過到期檢查、帶日期的企業版開通等於永不到期；現有的 `admin-set-user-permissions.yml` 只鎖定內部 `@sowork.tw` / `@sowork.ai` 信箱，而且會一併給 `role=admin`（外部客戶**不可以**這樣開）。→ 每一筆外部企業版成交，都必須先跟工程約好開通方式。

### ❌ 尚未實作 — **不得承諾**

`plans.ts` 的企業版 feature 字串目前寫著下列項目，但程式碼中**找不到對應實作**（該字串也還沒出現在任何對外頁面）：

| 字串上的承諾 | 現況 |
| --- | --- |
| 「客製品牌風格庫 + LoRA」 | 只有 PiAPI Flux 內建的 realism LoRA 預設，**沒有**依客戶品牌訓練 LoRA 的流程。 |
| 「SLA 服務承諾」 | 沒有 SLA 文件、沒有可用率量測、沒有違約補償條款。 |

## 4. 報價指引

企業版是議價制（系統中價格為 `-1`，畫面顯示「聯繫業務」），沒有 Stripe 自助結帳，走合約＋人工開通。

**定價地板（成本面）** — 內部成本基準：30 秒任務約 US$0.01、60 秒約 US$0.04、99 秒約 US$0.20、生圖約 US$0.04、影片每 5 秒片段約 US$1.00。企業版**沒有每日成本上限**，所以報價必須反過來從用量估：

> 月成本估算 ≈（每月任務數 × 任務單價）＋（每月圖片數 × US$0.04）＋（影片片段數 × US$1.00）

**建議錨點**

- 下限：不低於 Agency US$469／月（否則客戶會直接改買 Agency）。
- 常見起跳：以「品牌數 × 專業版 US$300」推估對照價，再給集團折扣。
- 加值服務（已公開標價，可直接引用）：
  - 策略顧問導入 **NT$80,000**（一次性，含客製任務卡 8 張；第 9 張起 NT$25,000／張）
  - AI 自動化報告 **NT$48,000 建置 ＋ NT$25,000／月維運**（標準範圍：1 品牌、1 市場、20 品項內；21–50 品項起依級距加購）
  - 兩項加購**都必須搭配專業版以上**。
- 點數加購包（如企業池需補值）：US$15／1,000 點、US$60／5,000 點、US$100／10,000 點；加購點數永不過期。

**合約必備條款（因為系統不會幫你擋）**

1. **用量上限寫進合約**：企業版跳過每日成本上限，系統端沒有任何煞車。請以「每月任務／生圖／影片數上限＋超量計價」約定。
2. **到期日寫進合約並設人工提醒**：企業版帳號**不受 `planEndsAt` 到期控制**，合約到期後系統不會自動停用，必須人工降級。
3. 影片若要納入範圍，須先確認該功能當期是否開放（其他方案目前一律關閉）。

## 5. 成交流程（業務 → Ops）

1. **資格確認**：多品牌／多部門／需要白牌或代客操作／需要集中控管用量 → 企業版；單一品牌只是想要更多內容量 → 專業版就夠，不要過度銷售。
2. **用量訪談**：每月要產幾篇、幾張圖、幾個品牌、幾位使用者、要不要發布排程。→ 換算成本 → 報價。
3. **範圍確認**：把第 3 節的「尚未實作」逐項對照客戶期待，**書面排除**。
4. **合約**：含用量上限、超量計價、到期日、白牌素材交付方式。
5. **開通（必須先跟工程確認）**：目前沒有對外客戶適用的企業版開通 workflow；請提前一週提出，避免簽約後卡在開通。
6. **導入**：品牌定位 → Brand Brain 建置 → 通路與任務卡設定 → 發布帳號 OAuth 連線 →（如需）企業點數池與每人上限設定。
7. **續約前 30 天**：人工檢查用量與合約到期日（系統不會提醒）。

## 6. 常見異議與回應

**「我們為什麼不直接買 Agency 就好？」**
> Agency 是自助方案：點數有每月上限、沒有共用點數池的逐人管控、沒有導入服務。企業版是合約制：無上限、集團共用池可逐人設定額度、每一筆消耗都有流水帳，加上導入與客製任務卡。若貴公司只需要無限品牌而不需要控管與導入，Agency 確實夠用——這點我們會誠實講。

**「有沒有 SLA？」**
> 目前不提供合約型 SLA。我們可以承諾的是專人窗口與導入支援；SLA 條款請等產品正式發布後再納入。（**不要自行承諾可用率數字**。）

**「可以部署在我們自己的機房嗎？」**
> 目前只有雲端 SaaS。私有部署還在規劃中，無法給時程。

**「可以用我們自己的品牌風格訓練模型嗎？」**
> 我們可以把品牌語氣、視覺方向、任務卡客製成 Brand Brain 與客製任務卡（導入服務範圍內）。專屬模型微調（LoRA）目前尚未提供。

**「資安與個資？」**
> 登入事件有稽核軌跡；使用者資料可匯出、可依請求刪除（30 天後硬刪）。SSO／SAML 目前尚未支援。

## 8. 內部帳號注意事項

`@sowork.tw` 與 `@sowork.ai` 結尾的信箱在系統中**一律視為企業版**（`billingRouter` 的網域政策），且品牌數不受限。示範時用內部帳號看到的「無限」畫面，與外部客戶實際開通後的畫面一致，但**內部帳號同時具備 admin 權限**，展示時請避開後台頁面。
