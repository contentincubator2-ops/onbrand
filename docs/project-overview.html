Brand Brain

判讀方式：本頁以 active import、route、runtime guard 與 adapter 為準。UI 出現不等於第三方 API 一定可用。

先定位內容不是每次從零，先共用品牌脈絡。
再協作依任務切換 Agent、模型、研究與 QA。
後執行輸出進專案、排程、發布與下一輪回饋。

How it works

從品牌資料到可發布成果

真正的主流程是 Brand Brain → 平台任務 → quickTaskOrchestra → mission/output → Projects／Calendar。舊 A2A endpoint 仍在，但不是目前一般 Web 任務的核心路徑。

建立品牌

輸入網站、品牌、產品、活動、目標市場與官方受眾。

鎖定定位

互動研究管線與背景 canonical runner 產出可重用 positioning。

選任務

依平台選 Single、Pack 或 Campaign，帶入 Brand Brain。

Agent 編排

載入資料、選模、產生文案與視覺 brief，再經品牌規則檢查。

編修成果

先寫入 caption checkpoint，再補媒體、extras、QA 與版本。

排程發布

成果進 Projects、Theater 與 Calendar；已連線渠道再執行發布。

API & AI map

不是固定一顆模型

最後成功的模型由 caller、任務分類、Agent 設定、env、fallback 與 circuit breaker 共同決定。requested model 也不一定等於真正完成呼叫的 model。

invokeLLM

通用 provider cascade、缺 key 略過、circuit breaker 與串流。

callModel

依中文、創作、分析、分類、搜尋、程式等任務選 provider。

callLLM

有時間預算的 Anthropic / Azure / OpenRouter 跨供應商救援。

LLM + billing

點數與 token ledger wrapper；尚未涵蓋所有直接 LLM 呼叫。

media dispatch

依 image/video model ID 分派 Google、OpenAI、PiAPI 等 adapter。

通用 invokeLLM 沒有覆寫時的預設順序是 Anthropic → OpenAI → Azure Claude → Azure Foundry → Gemini → Qwen → Zhipu → Ollama；缺 key、不可達或 circuit-open 會略過，LLM_FALLBACK_CHAIN 也可完整覆寫。

Qwen · qwen-plus Zhipu · glm-4-flash OpenAI · gpt-4.1-mini Anthropic · Claude Azure AI Foundry Google Gemini / Vertex Cohere alias → default Hermes explicit / Ollama fixed local fallback OpenRouter · legacy fallback

Architecture

主產品位於 skills/ai-talent。React SPA 經 tRPC／REST／SSE 進入 Express，再由 domain router 串接 orchestration、資料與第三方服務。

OnBrand Studio

  • React 18 + Vite 5
  • React Router 6
  • TanStack Query + tRPC client
  • HeroUI + Tailwind + Framer Motion
02 · API

Express Gateway

  • /trpc type-safe procedures
  • /api/auth 與 webhook

  • JWT cookie / Bearer context
03 · Domain

Routers + Orchestration

  • Brand / task / project

Storage + Providers

  • Pipedream / bundle.social

Reality check

文件上最容易誤判的地方

這些差異來自產品快速演進：UI 文案、註解、舊 blueprint 與 runtime 接線並不總是同步。

目前可以當核心產品理解

  • Brand Brain、品牌／產品／活動 scope 與定位資料。
  • 七渠道內容任務、quickTaskOrchestra、Run 與 Projects。
  • Theater、Calendar、策略顧問、帳號、帳務與 workspace。
  • 媒體模型 picker 中標為 Ready 的 adapter。
  • 支援、錯誤、成本與 activation 管理後台。

必須加註狀態才可對外描述

  • Performance / Market Intel 是私人預覽，多數為 curated demo。
  • 社群發布要看 connector、Meta 權限、feature flag 與平台支援。
  • 影片 API / UI 存在，但完整合成流程仍屬實驗性或依方案開放。
  • A2A workflow map 目前為空；community marketplace 尚無前台入口。
  • Azure AI Search 有查詢路徑，但沒有已接線的自動 index / delete 流程。
  • 不是每個 LLM 呼叫都經 billing wrapper，ledger 也可能記 requested model 而非實際 fallback。
  • 根 .env.example 與 runtime key 名稱已有落差；不能直接當完整設定清單。
  • 安全性事件、憑證輪替與弱點位置應只記錄於私人 security issue；公開文件僅保留一般性安全政策。
