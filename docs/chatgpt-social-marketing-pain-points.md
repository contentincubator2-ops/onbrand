# 老闆視角：用 ChatGPT 經營社群、媒體與行銷，會撞到什麼痛點

> 用途：定位與銷售素材。整理「老闆（決策者、付錢的人）」實際會遇到的痛點，而不是小編視角的使用心得。
> 對應產品：OnBrand AI。文末有痛點 → 本 repo 現有能力的對照，能力狀態沿用 `README.md` 的標記口徑。

---

## 0. 一句話結論

ChatGPT 解決的是「**寫不出來**」。
老闆的問題從來不是寫不出來，而是「**要穩定品質、要有人管、要能上架、要能交代成效**」。

所以典型的體感是：

- **老闆自己用 → 很驚豔**（單點任務、自己就是品牌本人、自己判斷好壞）
- **給團隊用 → 就崩了**（規模化、一致性、審核、稽核、交接全部沒有）

這個落差本身就是最好的銷售切入點：老闆不是不相信 AI，他是「相信 AI，但發現導入後公司沒有變輕鬆」。

---

## 1. 品牌層：越用越不像自己

| 症狀（老闆會說的話） | 真正的根因 |
|---|---|
| 「這不是我們講話的方式。」 | ChatGPT 沒有品牌記憶。每個對話都是新的，品牌資料要靠人每次重貼 |
| 「同一週 IG、FB、LINE 看起來像三家公司。」 | 每個小編自己一套 prompt、自己一個帳號，公司沒有唯一的語氣 source of truth |
| 「一看就知道是 AI 寫的。」 | 預設語感有明顯指紋：萬用形容詞、三點式條列、「在這個 ___ 的時代」開場、過度工整 |
| 「它把我們的規格 / 價格 / 保固講錯了。」 | 幻覺。而且是最貴的一種幻覺——對外講錯，客服善後 |
| 「它拿競品的說法來講我們。」 | 模型用的是訓練語料裡的產業通用說法，不是你的差異化 |

**代價**：品牌資產不但沒累積，還在稀釋。而且是慢性的，老闆通常在三到六個月後才發現。

**關鍵洞察**：Prompt 寫得再好，也只是「這一次講對」。品牌一致性需要的是**可重用、可版控、全公司共用的品牌記憶**，不是個人的 prompt 技巧。

---

## 2. 流程層：這是最大的痛點，但老闆最常低估

ChatGPT 給你的是**一段文字**，不是**一則可以發布的貼文**。中間的距離，全部由人力補。

**斷點清單：**

1. **沒有規格**：圖片尺寸、首行斷點（IG 前 125 字）、hashtag 數、CTA、連結貼法、平台字數限制——都要人再修一次
2. **沒有圖**：文案好了，設計還沒開始。設計檔回來後文案又要改
3. **沒有版本與審核軌跡**：產出散在幾十條對話紀錄裡。「這篇誰核准的？」「上一版是什麼？」查不到
4. **複製貼上稅**：一天 10 篇貼文，人工搬到 Meta / LINE OA / 官網後台，約 1.5–2 小時純搬運。一個月＝ 4 個工作天，只在做搬運
5. **沒有日曆視角**：檔期、節慶、活動、改期、下架、撞期，全靠 Excel 跟記憶
6. **社群「經營」≠ 發文**：留言、私訊、負評、社團、KOL 溝通、危機處理——ChatGPT 幾乎完全沒接到這些真實入口，但這些才是老闆說的「經營社群」

**代價**：老闆以為買了產線，實際只買到一台打字機。省下的寫稿時間，被搬運和校稿吃掉。

---

## 3. 組織層：工作量沒有消失，只是換了一個人做

| 導入前的期待 | 導入後的現實 |
|---|---|
| AI 產出 → 直接上線 | AI 產出 → **人工校稿** → 修圖 → 搬運 → 上線 |
| 可以少請一個人 | 人沒少，但變成「AI 的校稿員」，士氣下降 |
| 新人也能有 80 分產出 | 落差反而擴大：**不會問的人，產出更糟**，而且他不知道自己差 |
| 能力留在公司 | 能力留在**個人**。小編離職，他的 prompt、他的 GPT、他的對話紀錄全部帶走 |

**老闆真正的無力感**：他自己看不出輸出好在哪、壞在哪，只能說「這篇怪怪的」，然後要求重做。沒有標準，就無法管理；無法管理，就無法授權。

**另一個沒人講的成本**：老闆變成品牌的最後一道 QA。原本要放掉的事，反而更綁住自己。

---

## 4. 成本層：帳面很便宜，真實成本在別的地方

- **看得見的**：每人每月訂閱費。老闆覺得便宜，所以輕易同意
- **看不見的**：
  - 校稿與重做工時（通常是訂閱費的 5–20 倍）
  - 講錯話的善後成本（客服、退換貨、公關）
  - 帳號治理成本：個人帳號買、私人信用卡報帳、離職資料留在個人帳戶、無法稽核誰用了什麼
- **產出暴增但成效沒動**：內容量翻三倍，觸及沒動。老闆的感受是「花錢買了一堆沒人看的東西」
- **無法交代 ROI**：董事會問「AI 今年幫我們省了多少、賺了多少」，答不出來

---

## 5. 風險與合規層：老闆睡不著的那一層

1. **機密外洩**：客戶名單、未公開財報、報價策略、產品路線圖被貼進公開對話框
2. **法遵**：台灣的藥事法、化粧品衛生安全管理法、食品標示、公平交易法（不實廣告）、金融商品話術——AI 不知道你的產業紅線，而它寫得**非常有說服力**
3. **著作權與肖像**：生成圖、生成人物、生成音樂的商用風險，電商 / 醫美 / 食品最敏感
4. **假出處**：AI 引用不存在的研究、報導、數據，被抓到一次就是信任崩盤
5. **平台政策**：各平台對 AI 內容標示、自動化發布的規則在變
6. **拿不出紀錄**：被檢舉或客訴時，「誰在什麼時候核准了哪一版」——沒有稽核軌跡，無法自證

**這一層的特徵**：發生機率低，但單次代價極高，而且**責任一定落在老闆身上**。

---

## 6. 成效層：內容與數據完全脫鉤

- AI 不知道上週哪篇表現好，所以這週還是寫一樣的東西
- 沒有 A/B、沒有回饋迴圈 → **第 100 篇的品質等於第 1 篇**
- 市場情報不在 AI 腦裡：模型有知識截止日，不接即時搜尋就是在用過期資訊做行銷判斷
- 競品在做什麼、聲量在哪、負面訊號何時出現——完全沒有雷達

**老闆的結論**：「我不確定它有沒有用，但停掉又怕落後。」——這是最糟的狀態：**持續付費，但無法決策**。

## 7. 痛點速查表（銷售現場可直接用）

| 老闆的體感 | 表面問題 | 真正的根因 | 需要的不是更好的 prompt，而是 |
|---|---|---|---|
| 「不像我們的品牌」 | 語氣不對 | 沒有品牌記憶 | 可版控、全公司共用的 Brand Brain |
| 「每次都要重教一次」 | 重工 | 上下文不持久 | 品牌 / 產品 / 活動的結構化資料層 |
| 「產出很多但沒上線」 | 慢 | 產出 ≠ 可發布物 | 規格化任務 + 排程 + 直接發布 |
| 「誰核准的？」 | 混亂 | 沒有版本與審核 | 輸出工作區 + 版本 + 定稿紀錄 |
| 「人沒有變少」 | 沒省力 | 工作量轉移到校稿 | 內建 QA 與品牌檢核，而非人工把關 |
| 「小編走了就斷」 | 依賴個人 | 知識留在個人帳號 | 組織級的知識資產與權限 |
| 「不知道有沒有效」 | 無法決策 | 內容與數據脫鉤 | 成效回饋進下一輪內容生成 |
| 「怕出事」 | 焦慮 | 無稽核、無紅線 | 品牌禁用詞、產業紅線、可追溯紀錄 |

## 8. 誠實的邊界：什麼情況下 ChatGPT 就夠了

不要對所有人推平台。以下情況，ChatGPT 是**正確**的選擇，硬推只會失去信任：

- 一人公司 / 個人品牌，老闆自己就是品牌本人
- 月產出 20 篇以下，單一渠道
- 非管制產業，內容風險低
- 沒有交接需求、沒有稽核需求

**分水嶺**：當「**產出的人 ≠ 定義品牌的人**」的那一刻，一致性、審核、交接的成本就會出現，ChatGPT 的邊際效益開始下降。這句話可以直接拿來當銷售的判斷題。

---

## 9. 診斷問句（給業務 / 顧問，五題定生死）

1. 你們現在的品牌語氣，寫在哪裡？新人第一天可以拿到嗎？
2. 一篇貼文從「想到」到「上線」，經過幾個人、幾個工具、多少時間？
3. 上個月表現最好的三篇貼文是哪幾篇？**下個月的內容有因此改變嗎？**
4. 如果今天負責社群的人離職，下週的內容會怎麼樣？
5. 如果一則貼文出事，你能在十分鐘內拿出「誰、何時、核准了哪一版」嗎？

答不出第 3、4、5 題的老闆，就是 OnBrand 的客戶。

## 10. 痛點 → OnBrand 現有能力對照

> 狀態沿用 `README.md` 的口徑：**已接通**（前後端都接線）、**條件式**（需環境變數／第三方憑證／方案權限）、**私人預覽**（allow-list）。

| 痛點 | 對應能力 | 狀態 |
|---|---|---|
| 沒有品牌記憶、每次重教 | Brand Brain：品牌、產品、活動、受眾、語氣、品牌資產（`/brands`、`/brands/edit`） | 已接通 |
| 語氣不一致、不懂差異化 | 多步品牌定位研究：受眾、競品、Golden Circle、標語、語氣 | 已接通 |
| 產出 ≠ 可發布物 | 各平台任務工作區（FB / IG / LinkedIn / YouTube / TikTok / Email / PR），依平台規格產出 | 已接通 |
| 沒有版本、查不到誰核准 | 輸出工作區：編修、版本化、定稿、分享（`/run/:outputId`、`/projects`） | 已接通 |
| 文案好了但沒有圖 | 圖片 / 影片生成與視覺方向（多模型選擇器） | 已接通＋條件式 |
| 複製貼上稅、沒有日曆 | 內容日曆、排程、改期、發布（`/calendar`）。直接發布已接 FB / LinkedIn / IG；**YouTube、TikTok 直接發布明確未支援** | 已接通＋條件式 |
| 一週的內容要一次規劃完 | 7-Day Publisher／內容劇場（`/theater`），含 QA 與生圖 | 已接通＋條件式 |
| 老闆自己看不出好壞 | 策略顧問（`/consultant`）：五種情境框架、分析、追問、比稿 | 已接通 |
| 內容與數據脫鉤、沒有市場雷達 | Performance、Market Intel | **私人預覽**（部分為策展／示範資料，不可對客戶宣稱為完整成效歸因） |
| 成本不透明、無法控管 | 方案、點數、訂閱、多租戶 workspace | 已接通＋條件式 |

**銷售紀律**：對外只承諾「已接通」的項目；「條件式」要講清楚前置條件（憑證、方案）；「私人預覽」不可當成已上線能力銷售。
