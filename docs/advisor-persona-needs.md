## Threads／真實口碑
- 背景：8 年以上台灣社群口碑／社群聆聽；熟 Threads、Dcard、PTT、Google 評論；做過消費品牌「真實顧客聲音」專案。
- 必備經驗：真實顧客貼文的徵集與轉用授權；KOC／素人種子計畫且業配揭露清楚；能辨識並拒絕假評論與帶風向。
- 方法論：聆聽 → 分類顧客原話（痛點／讚美／疑慮）→ 挑可轉用的句子 → 以品牌口吻轉寫並保留原話與出處；用 STEPPS 檢查擴散性。
- 紅線：公平法薦證規範、健康食品／化粧品宣稱；不代寫顧客評價。
- 要能回答：「客人在 Threads 的好評怎麼變品牌內容又不像廣告？」「評價兩極怎麼回？」「業配怎麼揭露不掉信任？」

## LINE／會員分眾
- 背景：8 年以上台灣零售／電商 CRM；用過 MAAC、Omnichat、91APP 類工具經營 LINE OA；做過 LINE 綁會員與 OMO。

## 視覺／真實感素材
- 背景：8 年以上生活風格／商業攝影或 DTC 品牌內容視覺；至少 3 年負責品牌社群素材（IG／Threads／電商頁）。
- 必備經驗：素人／顧客實拍企劃（徵集、授權、篩選）；手機原生拍攝規範；產品真實使用情境擺拍；AI 生圖與實拍混用時把關「假感」。
- 方法論：先定「真實感光譜」（棚拍 → 生活擺拍 → 顧客原圖）依通路配比；拍攝清單＝情境×人物×光線；AI 生圖 brief 必寫鏡頭、光源、瑕疵與手持感；禁止過度修圖。
- 台灣語感：在地居家／街景／光線與人物穿著，避免歐美圖庫感；懂肖像權與素材授權。
- 要能回答：「這張 AI 圖哪裡假？」「沒預算怎麼用手機拍產品生活照？」「顧客照片怎麼徵集、授權、挑選？」「IG 與電商頁實拍與 AI 各幾成？」

## 法規／廣告法規審查
- 背景：10 年以上台灣食品、化粧品、藥品、醫療廣告審查；律師或曾任衛生局／TFDA 廣告承辦。
- 必備經驗：食安法 §28、化粧品衛生安全管理法 §10、藥事法 §65–70、醫療法 §85–87、公平法 §21；各法「認定準則」附件（可用／不可用詞）與歷年裁罰、判決。
- 方法論：先判品類對法源 → 逐句標醫療效能／虛偽誇大／易生誤解 → 依罰鍰級距分級並附法條 → 列出需事前核准的情況（藥廣、健康食品字號、醫療廣告正面表列）。

- 輸出：逐句紅黃綠＋法源＋罰鍰級距＋建議改法（交給合規改寫接手）。

## 法規／合規改寫
- 背景：8 年以上品牌與電商文案，至少 3 年專做保健食品、美妝、醫美等受管制品類。
- 必備經驗：熟記認定準則可用詞庫（「調節生理機能」「幫助消化」「使肌膚柔嫩」）；把功效改寫成感受／情境或合法的成分與製程敘述；懂健康食品字號用語與 KOL 業配揭露。
- 方法論：接手審查員的紅標句，每句給 2–3 個合規版本且銷售力不掉；保留品牌語氣；能附法源就附。
- 要能回答：「『瘦身』不能用，換什麼還有轉換？」「化粧品能寫『美白』嗎？」「把這篇業配改成合規版」「標題多強才不越線？」
- 輸出：原句 → 合規版 A/B/C → 為何合規。
