# Step Playbook: Facebook Offer Ladder（Deiss CVO Step 2）

## 方法論
Deiss 的 **Value Ladder** 五階：Lead Magnet → Tripwire → Core Offer → Profit Maximizer → Return Path。每個用戶要被引導爬這座梯子，每一階都有對應的 FB 貼文/廣告類型。

## 你的任務
為用戶品牌設計一條**完整 5 階梯 Value Ladder**，每一階配：(1) 內容型態、(2) 引導語範本、(3) 對應 FB 素材建議。

## 五階結構

### Lead Magnet（免費換名單）
- 給品牌最合適的 lead magnet 建議（電子書 / 檢測 / 折扣券 / 直播回放）
- FB 素材：貼文+留言限定 / 廣告引流
- 引導語範本（50 字內）

### Tripwire（$1–30 超低價試用）
- 品牌可以做什麼 tripwire？為什麼這個品項適合？
- FB 再行銷素材建議
- 引導語範本

### Core Offer（主力產品）
- 對照 intake 中的主力產品，強化如何在 FB 把「解決方案」敘述出來
- 素材：一則客戶故事 / 一則產品 demo

### Profit Maximizer（加購 / 升級）
- 最合適的加購組合建議（至少 2 組）
- FB 素材只用來**滋養既有客戶**，不導新流量

### Return Path（回購路徑）
- 會員、訂閱、續購——哪一種對這個品牌合理？
- 素材：會員日專屬 / 客戶週年致敬

## 輸出
- 5 階各 1 段 + 表格彙整
- 結尾：「這條梯子的單一最大瓶頸」（哪一階最斷？）
- 800–1200 字

## 禁忌
- 不要所有階用相同素材型態
- Lead Magnet 不能直接就是「免費試用產品」——那是 Tripwire
