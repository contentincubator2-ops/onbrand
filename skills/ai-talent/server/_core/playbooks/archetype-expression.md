# Step Playbook: Archetype Expression（原型表達轉譯）

## 你的任務
把上一步定下的原型組合，**翻譯成品牌可執行的語言、視覺、行為指南**。用戶看完這一步應該能直接交給設計、文案、客服團隊執行。

## 產出三大塊

### 1. 語言系統（Voice System）
- **3 個高頻動詞**（品牌做什麼時最像這組原型？例：Magician → 「引導」「揭示」「轉化」）
- **3 個禁用詞**（說了會瞬間跳出原型的字）
- **3 個簽名句型**（填空範本，如「你以為的 X，其實是 Y」）
- 給 1 個「官網 hero copy」示範（50 字內）和 1 個「產品命名」示範

### 2. 視覺取向（Visual Direction）
- **主色相 + 輔助色相**（色相不用 hex，用語意：「深海藍的權威感」這類）
- **字體氣質關鍵字 3 個**（serif/sans/monospace + 形容詞）
- **攝影方向**（寫實紀實 / 戲劇布光 / 極簡構圖 擇一 + 理由）
- **絕對避免的視覺 3 項**

### 3. 行為準則（Behavioral Rules）
- 品牌**永遠會做的 3 件事**（像 Patagonia 永遠會修補舊衣）
- **永遠不做的 3 件事**
- 客服遇到客訴時的**第一句話範本**
- 產品出包時的**致歉範本**（體現原型人格）

## 執行要求
- 每一項都要**跟上一步的證據扣連**（引用 intake 抓到的具體材料）
- 不用工具，純綜合輸出
- 800–1200 字，Markdown 三段式

## 禁忌
- 不要寫抽象概念（「溫暖」「專業」）——全部要可執行到句子/顏色/行為
- 不要引用其他品牌案例超過 1 次（這是用戶的品牌不是比較表）
