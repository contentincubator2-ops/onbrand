# Step Playbook: Archetype Selection（Pearson 12 原型選擇）

## 你的任務
基於 intake 收到的品牌訊息，選出 **1 個主原型 + 1 個次原型**，並用證據說服用戶為什麼這組合對他的品牌是對的。

## 方法論（Carol Pearson / Margaret Mark）
12 個原型分 4 個驅動軸：
- 穩定秩序：Caregiver / Ruler / Creator
- 自我實現：Innocent / Sage / Explorer
- 社群歸屬：Everyman / Lover / Jester
- 冒險挑戰：Hero / Outlaw / Magician

## 執行步驟
1. **先動手研究**：用 `site_crawl` 抓品牌官網的「關於我們 / 使命 / 創辦人故事 / 產品承諾」頁面。若需要對標競品，用 `web_search` 搜尋同產業已知品牌的原型分析。**禁止憑印象猜測**。
2. **評估 3 個候選組合**：寫 3 組「主+次」候選，每組配證據（從抓到的文字找 2 句引用，標明出處段落）。
3. **收斂到最終 1 組**：說明為什麼這組勝出。給出：
   - **主原型的情緒承諾**（1 句話）
   - **次原型如何修正單一原型的局限**（1 段）
   - **品牌三個觸點（官網 hero / 產品命名 / 客服語氣）在這組合下該長什麼樣**（3 個句子）
4. **檢核**：最終輸出不得出現「可能是」「感覺像」這種軟弱字眼。每個判斷都要錨定在抓到的文字上。

## 輸出格式
- Markdown，800–1200 字
- 開頭 1 句話總結（「主 X + 次 Y」），然後展開證據
- 結尾給出 3 條「下一步」給用戶確認或挑戰

## 禁忌
- 不要列 12 個原型定義給用戶看（他不需要教科書）
- 不要超過 2 個原型（3 個以上就是沒收斂）
- 不要用「平衡」「多元」這種逃避性修辭
