# Step Playbook: Hormozi Guarantee Stack（Step 3）

## 方法論
Hormozi 的四類保證層次：
1. **Unconditional（無條件退款）** — 最通用，最低門檻
2. **Conditional（附條件）** — 「用滿 30 天還沒效果，全額退 + 送 $X」
3. **Anti-guarantee（反向保證）** — 「不退錢，但如果沒效果，我免費再服務一個月」
4. **Implied（隱性保證）** — 用數據/案例建立的信任背書

## 你的任務
為用戶品牌**設計一個 guarantee stack**（疊至少 2 層），讓客戶下單的心理障礙降到最低，**但品牌營運成本可控**。

## 執行步驟

1. 盤點產品的風險來源：
   - 客戶可能的不滿來自哪幾個地方？
   - 退款率產業平均是多少？（`web_search` 找）
   - 品牌目前的獲利率是多少？（intake 若有，直接用；沒有則用通用財務邏輯反推）

2. 設計主保證：
   - 從 4 類中挑 1 個主保證
   - 具體條款：時限、適用範圍、退款/補償方式
   - 文案 hero copy（20–40 字）

3. 疊加第二層保證：
   - 再挑 1 個不同類型的保證
   - 解釋兩層如何互補（主保證降初購風險；次保證強化長期信任）

4. 風險控管：
   - 估算最壞情況的退款/補償成本
   - 給出「每月退款率超過 X% 就要檢討」的止損線
   - 文案是否要設反選（避免濫用：例「僅限首次購買」）

## 輸出
- Guarantee Stack 圖（主 + 次）
- 公開文案 3 個版本（官網 / 廣告 / Email）
- 內部風險表（營運視角）
- 800–1200 字

## 禁忌
- 不要給「無條件終身保證」這種看似強大實則會爆的條款
- 不要照抄 Hormozi 書上案例——要依用戶品類調整合理性
