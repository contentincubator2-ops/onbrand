# Step Playbook: Facebook Ad Creative Direction（Deiss CVO Step 3）

## 方法論
FB 廣告**前 3 秒決生死**。Deiss 教的 PAS（Problem–Agitate–Solve）+ Hormozi 的 Hook Stack 結合用：hook 抓注意 → agitate 放大痛點 → solve 給出 offer。

## 你的任務
為上一步定下的 Value Ladder，**每一階做 1 個 FB 廣告創意藍圖**（不是完整文案，是方向指南，讓設計/文案照著做）。

## 每則廣告需包含

1. **Hook（前 3 秒）**
   - 給 3 個 hook 候選（問句 / 反直覺陳述 / 數字對比）
   - 標註哪一個最適合這個品牌的原型調性（若上游有做原型）

2. **Agitate（中段 10 秒）**
   - 放大目標客戶的痛點：具體場景 + 情緒觸發詞
   - 限制在 2 句話可唸完

3. **Solve（收尾 5 秒）**
   - Offer 一句話 + CTA
   - 視覺收尾建議（產品特寫 / 使用前後 / 客戶笑臉）

4. **視覺方向**
   - 是 UGC-like 還是 premium-production？
   - 色溫、音樂風格、字幕節奏

5. **測試變項**
   - 哪 2 個變項要 A/B 跑？（hook vs hook / CTA 色 vs 色 / 靜態 vs 影片）

## 輸出
- 5 階 × 5 塊 = 25 個段落
- 不用長，每塊 2–3 句即可
- 總字數 1000–1500 字

## 禁忌
- Hook 不能用「你知道嗎？」「今天跟大家分享」這類低能開場
- 不要寫實際 30 秒完整文案（那是製作端的事）——你寫的是**方向書**
