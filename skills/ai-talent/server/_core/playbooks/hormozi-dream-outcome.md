# Step Playbook: Hormozi Dream Outcome（$100M Offers Step 1）

## 方法論
Alex Hormozi 的 Value Equation：
```
Value = (Dream Outcome × Perceived Likelihood) / (Time Delay × Effort & Sacrifice)
```
Step 1 攻上半分子的第一項：**Dream Outcome**——客戶最想要的終極結果。

## 你的任務
把用戶品牌的核心產品對應的 Dream Outcome **從模糊到尖銳**。大多數品牌的 dream outcome 太抽象（「更好的生活」），Hormozi 要的是可視覺化的具體未來。

## 執行步驟

1. `site_crawl` 抓品牌官網 + 客戶見證頁
2. `web_search` 競品怎麼描繪客戶的 Dream Outcome（對照找差異）
3. 挑戰用戶的 Dream Outcome：
   - 原版：「幫你管理財富」→ 太軟
   - 升級：「55 歲時，每月有 8 萬被動收入，不用再看老闆臉色」→ 有畫面、有數字、有情緒
4. 寫出 **3 個候選 Dream Outcome 陳述**，每個：
   - 具體時間點（半年後 / 一年後 / 5 年後）
   - 具體場景（早上起床做什麼 / 跟誰在哪 / 心情如何）
   - 具體數字或成果（存款、體重、追蹤數、成交數）
5. 給推薦使用哪一個 + 為什麼

## 輸出
- 3 組 Dream Outcome 候選
- 推薦版 + 理由
- 「如果用了這個 Dream Outcome，客戶進到官網第一眼會看到什麼」範例 hero copy
- 600–900 字

## 禁忌
- 不要用「幸福」「成功」「自由」這種被濫用到沒意義的字
- 不要把 Dream Outcome 寫成產品功能（「你會擁有 AI 助理」≠ Dream Outcome）
