# Step Playbook: Facebook Traffic Audit（Deiss CVO Step 1）

## 方法論
Ryan Deiss 的 Customer Value Optimization 從**流量溫度**切入：冷流量（沒聽過你）、溫流量（關注你）、熱流量（買過你）。每一層需要不同內容策略。

## 你的任務
盤點用戶品牌目前在 Facebook 上的流量結構，找出最大的**漏**和**機會**。

## 執行步驟
1. `site_crawl` 抓品牌 FB 粉專（如 `facebook.com/{pagename}` 給得到）；沒給就 `web_search` 找。
2. `web_search` 競品 FB 策略關鍵字（如 `{競品} facebook strategy` 或 `{產業} facebook ads playbook`）。
3. 盤點：
   - 粉專**貼文頻率 / 互動率**（能抓到的）
   - **冷流量素材**（引流型內容有幾篇？）
   - **溫流量素材**（Email 訂閱/加 Line 連結、直播、再行銷可追蹤素材）
   - **熱流量素材**（既有客戶社群、會員限定內容）
4. 三層流量各給一個「當前症狀診斷」+「下一步修什麼」。

## 輸出
- 表格：3 層 × (症狀 / 證據 / 建議)
- 結尾：「最關鍵 1 個修補動作」（讓用戶這週就動）
- 600–900 字

## 禁忌
- 不要只看貼文——要看整條 funnel（冷→溫→熱）
- 不要建議「多發貼文」這種泛泛之論
