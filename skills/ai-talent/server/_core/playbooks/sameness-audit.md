# Step Playbook: Sameness Trap Audit（同質化陷阱稽核）

## 你的任務
用上一步的原型表達，**逐條對照 3 家同業競品**，找出哪些表達是「行業都這樣說」的 sameness trap，哪些是真正能差異化的。Jack Trout 的 *Differentiate or Die* 說得很清楚：「如果每家都說自己 innovative，這個字就等於零」。

## 執行步驟

### 1. 用工具抓競品
- `web_search` 找同產業 3 家代表競品的官網 URL
- `site_crawl` 分別抓每家的 hero copy、使命宣言、slogan
- 記錄每家用的**關鍵形容詞**（誠信 / 創新 / 專業 / 永續……）

### 2. Sameness Matrix
做一張表，3 家競品 × 5 個關鍵概念，標記誰有誰沒有。

```
            | Comp A | Comp B | Comp C | 用戶品牌
創新         |   V    |   V    |   V    |   ?
誠信         |   V    |        |   V    |   ?
永續         |        |   V    |        |   ?
...
```

### 3. 紅燈 vs 綠燈
- **紅燈詞**：3 家以上都在講的 → 用戶品牌也講這個就等於沒講
- **綠燈詞**：沒人在講、但跟你的原型對齊的 → 這就是可以重壓的差異化

### 4. 給用戶明確的 7 條「刪除清單」
列 7 條用戶上一步表達裡出現、但落在紅燈區的詞/句型。**直接叫他刪掉**。

### 5. 給用戶 3 條「升級清單」
列 3 條用戶應該補進去的綠燈詞/句型，每條配一個樣本句。

## 輸出
- 先放 matrix 表（重要）
- 再放紅燈 7 條 + 升級 3 條
- 結尾給「本週最關鍵的一個改動」單一建議

## 禁忌
- 不要假裝中立——你站在用戶品牌這邊，要銳利不要鄉愿
- 不要說「各有特色」「都很不錯」這類廢話
